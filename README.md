# Sham Ashik — Performance Marketing Portfolio

Responsive, static portfolio website. No database, API key, or paid server required.

## Go live on Vercel

1. Extract the ZIP file.
2. Visit https://vercel.com/new and sign in.
3. Import a GitHub repository with this folder (or use Vercel CLI: `npx vercel --prod` from the extracted folder).
4. For dashboard import, set Framework Preset to **Other**, Build Command **none**, Output Directory **public**.
5. Deploy. Vercel will provide a live `*.vercel.app` URL.

Alternatively use Netlify Drop: drag the `public` folder to https://app.netlify.com/drop for instant static hosting.

## Files
- `public/index.html` — website markup
- `public/styles.css` — styling
- `public/assets/Sham-Ashik-Portfolio.pdf` — downloadable original five-page portfolio
- `public/assets/Sham-Ashik-CV.pdf` — downloadable CV
- `public/assets/portfolio_page_*.png` — slide previews

## Updating
Replace the PDF files while keeping their filenames and redeploy. Edit `public/index.html` for text/case studies.

## Notes
All case-study figures are from the supplied portfolio; user must keep these figures accurate as newer campaign data becomes available.
